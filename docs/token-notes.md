## Процедура выдачи токена (implicit flow, вручную)

1. Открыть `https://oauth.yandex.ru/authorize?response_type=token&client_id=<CLIENT_ID>`.
2. Разрешить доступ; из адресной строки скопировать `access_token`.
3. Проверить (не вставляя токен в чат/git):
   `curl -s -H "Authorization: OAuth $TOKEN" "https://cloud-api.yandex.net/v1/disk/" | head -c 400`
   — ожидаем JSON с `total_space`, `used_space`, `user.login`, не 401.
